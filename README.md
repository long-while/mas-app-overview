# Nalda 디자인 명세

Nalda(역극·커뮤용 마스토돈 앱)의 iOS · Android 화면 설계 초안을 한 곳에서 보는 사이트입니다.

**보기:** https://longwhile.site/mas-app-overview/

| 보기 | 내용 |
|---|---|
| 소개 | 앱 소개, 이 문서의 목적, 고정할 것과 자유롭게 바꿔도 되는 것 |
| 핵심 흐름 | 처음 시작하기 · 타임라인 · 글쓰기 · 채팅 · 알림과 멘션 · 프로필 대표 화면 |
| 전체 화면 | 148개 화면을 기능별 10개 묶음으로(TL-01 같은 번호, 검색, 목차) — 누르면 크게 보기 |
| 한 화면 | 한 화면을 크게, iOS · Android 나란히 비교 |
| 아이콘 · 색상 | SVG 아이콘 모음, 테마별 색 토큰과 Swift · Kotlin · CSS 이름 |
| 부록 | 변경 기록, 용어 풀이 |

플랫폼(iOS / Android), 테마(White / Dim / Black), 글자 크기는 위쪽 바에서 고르고, 고른 상태는 주소에 남아 링크로 공유할 수 있습니다.

이 저장소의 파일은 생성물입니다. 원본은 디자인 핸드오프 폴더이고 `python tools/build-site.py <이 저장소 경로>`로 다시 만듭니다.
